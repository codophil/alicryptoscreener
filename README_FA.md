# Altcoin Radar — راهنمای راه‌اندازی رایگان

این نسخه آزمایشی/آموزشی است و سیگنال خرید یا تضمین سود نیست. برای استفاده واقعی ابتدا عملکرد و خطاهای احتمالی آن را ارزیابی کنید.

## ۱. بات تلگرام بسازید

1. در تلگرام `@BotFather` را باز کنید.
2. `/newbot` را بزنید و یک نام و username که به `bot` ختم می‌شود انتخاب کنید.
3. توکن را فقط نزد خودتان نگه دارید؛ آن را در فایل یا چت عمومی نگذارید.
4. یک کانال عمومی بسازید (مثلاً نام کاربری `@my_altcoin_alerts`) و ربات را Admin با اجازه Post Messages کنید. در این حالت `TELEGRAM_CHAT_ID` می‌تواند `@my_altcoin_alerts` باشد.
5. برای دریافت در پیام خصوصی، به بات `/start` بدهید، سپس در مرورگر خودتان آدرس `https://api.telegram.org/bot<TOKEN>/getUpdates` را باز کنید و `message.chat.id` را پیدا کنید. URL شامل توکن را با کسی به اشتراک نگذارید.

## ۲. مخزن GitHub بسازید

1. از `https://github.com/signup` حساب رایگان بسازید.
2. New repository را باز کنید و `altcoin-radar` را انتخاب کنید.
3. پیشنهاد: مخزن Public باشد تا سهمیه دقیقه Actions عمومی رایگان باشد. **توکن را داخل مخزن قرار ندهید.**
4. فایل‌های `radar.py`, `state.json`, `README_FA.md` و `.github/workflows/radar.yml` را با حفظ مسیر داخل مخزن آپلود کنید. فایل GitHub workflow حتماً باید در `.github/workflows/` قرار گیرد.

## ۳. اسرار امن GitHub را ثبت کنید

Settings → Secrets and variables → Actions → New repository secret

- `TELEGRAM_BOT_TOKEN`: توکن دریافتی از BotFather
- `TELEGRAM_CHAT_ID`: شناسه عددی چت یا `@username` کانال عمومی که بات اجازه پست دارد

## ۴. تست و اجرای واقعی

1. Actions → Altcoin Radar → Run workflow → `test_mode=true` → Run workflow.
2. اگر پیام تست رسید، دوباره Run workflow و `test_mode=false` را انتخاب کنید.
3. سیستم به‌صورت خودکار در دقیقه‌های ۷، ۲۲، ۳۷ و ۵۲ هر ساعت به‌وقت UTC برنامه‌ریزی شده است. اجرای GitHub ممکن است با تأخیر انجام شود یا بعضی نوبت‌ها از دست بروند.
4. اگر هیچ پیام معاملاتی نیامد، الزاماً خطا نیست: فقط گزینه‌های دارای فیلترهای کافی ارسال می‌شوند. نتیجه هر اجرا در قسمت Actions > job logs نمایش داده می‌شود.

## روش اسکن

- آلت‌کوین‌های USDT در بازار Spot بایننس با حجم ۲۴ساعته بالای ۵ میلیون USDT؛ ۵۵ مورد اول از نظر حجم بررسی می‌شوند.
- روی آخرین کندل بسته‌شده ۱۵ دقیقه‌ای RVOL با ۲۰ کندل قبلی مقایسه می‌شود؛ آستانه ۲ برابر.
- رشد قیمت چهار کندل ۱۵ دقیقه‌ای: بین ۰٫۵٪ تا ۷٪.
- RSI چهارده دوره‌ای روی ۱۵ دقیقه: ۴۸ تا ۷۴.
- امتیاز الگوریتمی حداقل ۷۰ از ۱۰۰؛ شکست سقف ۲۰ کندل قبلی در امتیاز موثر است.
- در هر اجرا نهایتاً ۳ پیام؛ برای هر ارز حداکثر یک پیام در بازه شش‌ساعته.
- معیارها صرفاً برای آزمایش هستند؛ درصد موفقیت یا احتمالی بودن سود را نشان نمی‌دهند.

## محدودیت‌ها

- معاملات به صورت خودکار انجام نمی‌شود و API معاملاتی لازم نیست.
- فعلاً Open Interest و Funding در الگوریتم **وجود ندارند**. می‌توان نسخه دوم با Coinalyze ساخت.
- اولویت به ۵۵ جفت نقدشونده داده شده، بنابراین بسیاری از آلت‌کوین‌های کوچک پوشش داده نمی‌شوند.
- Github Actions جایگزین پایش لحظه‌ای و بدون تأخیر نیست.
- اطلاعات بازار ممکن است به علت محدودیت شبکه/منطقه یا rate-limit در دسترس نباشد.
- state.json به صورت commit در مخزن ذخیره می‌شود، بنابراین مخزن عمومی تاریخچه هشدارهای قبلی را نمایان می‌کند؛ توکن‌ها در Secrets هستند.
- اگر در GitHub Actions دسترسی نوشتن GITHUB_TOKEN بسته باشد، بخش ذخیره state خطا می‌دهد. Settings → Actions → General → Workflow permissions را بررسی و اجازه Read and write را بدهید، اگر سیاست مخزن اجازه می‌دهد.
- اجرای schedule در مخازن عمومی پس از ۶۰ روز بدون فعالیت ممکن است غیرفعال شود؛ commit های state فعالیت ایجاد می‌کنند، اما در زمان نبود سیگنال باید این موضوع را هم بررسی کرد.

## امنیت

توکن ربات را در کد، فایل README، issue یا پیام عمومی منتشر نکنید. اگر لو رفت با BotFather آن را revoke کنید. استفاده از API داده عمومی نیازمند کلید بایننس نیست.
