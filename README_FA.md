# راهنمای نصب OKX Altcoin Watcher V4

## پیش‌نیاز
تنها یک مخزن GitHub و یک ربات Telegram با دو GitHub Actions Secret زیر:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

**هیچ حساب یا کلید API برای OKX لازم نیست.** برنامه از داده‌های عمومی SWAPهای USDT استفاده می‌کند. کتابخانه جانبی پایتون هم لازم نیست.

## روش تعویض با ربات قدیمی
1. ZIP را باز کن.
2. وارد مخزن موجود GitHub شو، خود مخزن و Secrets را حذف نکن.
3. **فایل‌های قدیمی را غیرفعال یا حذف کن**: به‌خصوص `.github/workflows/radar.yml` و `.github/workflows/watcher.yml` قدیمی. اگر فایل `watcher.yml` قدیمی داری، **محتوای آن را با نسخه داخل همین بسته جایگزین کن** (دو workflow با کار یکسان فعال نماند).
4. چهار فایل اصلی `watcher.py`، `config.json`، `state.json` و `tests/test_watcher.py` را در مسیر مشخص جایگزین کن. `state.json` نسخه جدید `{}` است و تاریخچه نسخه‌های قبلی را پاک می‌کند (برای شروع تمیز مناسب است).
5. فایل `.github/workflows/watcher.yml` نسخه جدید را در همین مسیر ایجاد/جایگزین کن.
6. README_FA.md جدید را هم آپلود کن.
7. Commit changes را بزن.

برای ویرایش پوشه‌ها می‌توانی در صفحه مخزن دکمه `.` را بزنی تا github.dev باز شود. پوشه `.github` ممکن است در کامپیوتر مخفی باشد؛ در این صورت نمایش فایل‌های مخفی را فعال کن. مطمئن شو مسیر فایل workflow دقیقاً `.github/workflows/watcher.yml` است.

## اجازه ذخیره تاریخچه
`Settings → Actions → General → Workflow permissions` را باز کن و اگر ممکن بود `Read and write permissions` را فعال و Save کن. این امکان به‌روزرسانی `state.json` بعد از اسکن موفق را می‌دهد. اگر Branch Protection مانع Push باشد، باید متناسب با سیاست مخزن اصلاح شود.

## تست
`Actions → OKX Altcoin Watcher V4 → Run workflow`
- ابتدا `test_mode=true` و Run workflow؛ پیام آزمایشی تلگرام را چک کن.
- سپس `test_mode=false` و Run workflow؛ log بخش `Scan and notify` را بخوان.
- در اجرای اول OI change معمولاً N/A است: پروژه تازه snapshot اولیه را در `state.json` می‌نویسد.
- اجرای بعدی در فاصله ۳ تا ۱۳ دقیقه می‌تواند تغییر OI را محاسبه کند. تأخیر GitHub ممکن است این فاصله را نامناسب کند. برنامه OI را در این حالت حدس نمی‌زند.
- موفق بودن اجرای اسکن بدون پیام طبیعی است اگر هیچ ارز واجد شرایط نباشد.

## برنامه زمان‌بندی
کران GitHub در دقیقه‌های ۳،۸،۱۳... هر ساعت و بر اساس UTC اجرا می‌شود؛ تأخیر ممکن است. اجرای واقعی ممکن است بیشتر از ۵ دقیقه فاصله داشته باشد. این سیستم اسکن دوره‌ای است نه استریم زنده بازار.

## تنظیمات `config.json`
- `max_pairs`: تعداد قراردادهای پرگردش برای بررسی (پیش‌فرض ۵۵).
- `min_24h_turnover_usdt`: حداقل گردش روزانه تقریبی به دلار.
- `max_alerts_per_run`: تعداد حداکثر پیام در هر اجرا.
- `awakening`: جهش حجم + حرکت محدود + رشد Open Interest.
- `momentum`: حرکت زیاد قیمت و جهش حجم، در هر دو جهت.
- `early_buy`: قیمت مثبتِ نه‌چندان زیاد + حجم + نمونه فشار خرید بالاتر + رشد OI.
- `whale`: هشدار **معامله انجام‌شده بزرگ** در حداکثر ۱۵ قرارداد پرگردش و آخرین ۱۰۰ معامله قابل بازیابی؛ **نه** پایش همه سفارش‌های دفتر سفارش. ممکن است معامله‌های زیادی را نبیند.
- `cooldown_minutes`: محدودیت تکرار جداگانه در هر ارز/نوع/جهت.

## نکته داده‌ها
- حجم ۵ دقیقه = `volCcyQuote` در کندل کامل OKX (USDT).
- RVOL = حجم کندل کامل اخیر تقسیم بر متوسط ۳۰ کندل کامل قبلی (۱۵۰ دقیقه).
- Move = درصد تغییر دو کلوز متوالی ۵ دقیقه‌ای.
- Pressure فقط از **نمونه ۱۰۰ معامله اخیر** محاسبه می‌شود؛ معادل فشار همه معاملات پنج‌دقیقه‌ای نیست. این عدد در پیام با عنوان `recent trades sample` مشخص است.
- OI change = تغییر تعداد قرارداد باز (`oi`) بین دو اجرای متوالی؛ با فاصله واقعی دقیقه، نه الزاماً دقیقاً پنج دقیقه.
- اندازه معامله بزرگ = قیمت × تعداد قرارداد × ارزش هر قرارداد (`ctVal`)؛ فقط در قراردادهای خطی که `ctValCcy` همان ارز پایه است.
- Score یک امتیاز قواعد داخلی است نه احتمال رشد.

## رفع خطا
- `HTTP 403/451`: احتمال محدودیت دسترسی OKX از runner جدید؛ از log بررسی کن. تست قبلی موفق بوده اما دسترسی همه IPها تضمین نیست.
- `Missing TELEGRAM...`: نام Secrets را در Settings → Secrets and variables → Actions بررسی کن.
- `Telegram HTTP 400/403`: چت‌آیدی، `/start` در گفتگوی خصوصی، یا دسترسی Admin بات به کانال را بررسی کن.
- `No eligible USDT swaps`: ممکن است پاسخ API تغییر کرده باشد یا شروط بیش از حد سخت‌گیرانه شده باشند.
- `Persist state` قرمز: به GitHub Actions مجوز نوشتن بده؛ وگرنه هشدار تکراری و OI ناقص خواهی داشت.

## چک بعد از نصب
در تب Actions مطمئن شو فقط `OKX Altcoin Watcher V4` برای اسکن بازار فعال است. Workflowهای آزمایشی `check-binance.yml`, `check-okx-final.yml` و `check-alternatives.yml` را می‌توان حذف کرد؛ چون `workflow_dispatch` هستند خودکار اجرا نمی‌شوند.
