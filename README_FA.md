## راهنمای پایه V5 (تنظیمات زمان‌بندی و OI بالا جایگزین موارد قدیمی هستند)

# Altcoin Market Watcher V5

نسخه مستقل چندبازاری. فقط داده عمومی، بدون سفارش‌گذاری یا حساب صرافی. Python 3.12 و کتابخانه استاندارد؛ هیچ وابستگی نصب‌شدنی یا API Key جدید لازم نیست.

## نصب در مخزن فعلی

1. در GitHub وارد Actions شوید، V4 را موقتاً Disable workflow کنید تا وسط جایگزینی اجرا نشود. خود Repository را حذف نکنید.
2. فایل ZIP را Extract کنید. در شاخه پیش‌فرض (برای مخزن شما master) فایل‌های `watcher.py`، `config.json`، `state.json`، `README_FA.md`، `tests/test_watcher.py` و `.github/workflows/watcher.yml` را با فایل‌های جدید جایگزین کنید. فایل workflow قدیمی دیگری مانند `radar.yml` را حذف یا غیرفعال کنید. فایل‌های تست دسترسی قبلی در صورت نیاز می‌توانند بمانند، چون فقط دستی اجرا می‌شوند. فایل `state.json` جدید عمداً وضعیت V4 را ریست می‌کند.
3. از Settings → Secrets and variables → Actions مطمئن شوید `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` وجود دارند؛ مقادیر را تغییر ندهید و هرگز داخل کد نگذارید.
4. Settings → Actions → General → Workflow permissions: مجوز Read and write permissions (اگر سیاست مخزن اجازه بدهد). Workflow به `contents: write` نیاز دارد. محافظت شاخه نباید مانع ثبت `state.json` شود.
5. همه فایل‌ها را Commit کنید. در Actions، `Altcoin Market Watcher V5` را باز کنید. اگر Enable workflow نمایش داده می‌شود، فعال کنید.
6. Run workflow → `test_mode=true`: فقط تست تلگرام. سپس `test_mode=false`: اسکن واقعی. `dry` فقط اسکن و گزارش پیام‌های پیشنهادی در لاگ است؛ تاریخچه را ثبت نمی‌کند و تلگرام نمی‌فرستد.
7. پس از اولین اجرای موفق واقعی، صبر کنید اجرای schedule بعدی انجام شود یا پس از ۵ دقیقه اجرای واقعی دیگری بگیرید. OI برخی منابع به نمونه قبلی نیاز دارد. اجرای خودکار به صورت cron هر پنج دقیقه درخواست می‌شود؛ GitHub ممکن است اجرا را به تأخیر بیندازد یا حذف کند. برای ذخیره و تداوم OI حتماً مرحله Persist state سبز باشد.

## تنظیمات پیش‌فرض

- OKX Futures، Gate Futures، KuCoin Futures، Binance Spot و DEX فعال؛ GeckoTerminal منبع کمکی کشف DEX.
- هیچ سقف ثابت برای تعداد قراردادها در هر CEX وجود ندارد (`max_pairs_per_source=0`). همه بازارهای واجد شرایط در حدود زمان و نرخ درخواست اسکن می‌شوند؛ اگر تمام نشوند اجرای بعدی از ادامه فهرست آغاز می‌شود. در KuCoin اگر گردش ۲۴ساعته در فهرست موجود نباشد، مجموع کندل‌های در دسترس تا ۲۴ ساعت به عنوان حد پایین استفاده می‌شود.
- حداقل گردش ۲۴ساعته: ۲۵۰ هزار USDT/USD؛ حداقل حجم پنج‌دقیقه‌ای: ۳۰ هزار. گردش روزانه OKX با حجم ارز پایه × آخرین قیمت برآورد می‌شود؛ DEX از داده دلاری گزارش‌شده استفاده می‌کند. USDT تقریب دلار است.
- مبنای حجم CEX: شش کندل پنج‌دقیقه‌ای بسته‌شده قبل از کندل هدف (۳۰ دقیقه)، با رد داده گمشده یا ناپیوسته. DEX: میانگین معادل پنج دقیقه از ۵۵ دقیقه قبل (حجم یک ساعت منهای حجم ۵ دقیقه، تقسیم بر ۱۱). پنجره DEX متحرک است و با کندل CEX متفاوت است.
- AWAKENING: حجم نسبی ≥۳ و قدرمطلق حرکت ≤۲٫۵٪؛ OI و فشار خرید/فروش به امتیاز کمک می‌کنند ولی برای جلوگیری از حذف همه پیام‌ها اجباری نیستند.
- MOMENTUM: حجم نسبی ≥۳ و قدرمطلق حرکت ≥۲٪؛ صعود و نزول هر دو.
- EARLY BUY WATCH: فقط فیوچرز؛ حجم نسبی ≥۴، رشد ۰ تا ۲٪، فشار خرید ≥۵۵٪، OI ≥۰٫۵٪. اگر داده کافی نیست صادر نمی‌شود.
- NORMAL: حداقل فیلترها؛ STRONG: حجم ≥۲۰۰ هزار و امتیاز ≥۵؛ HOT: حجم ≥۵۰۰ هزار و امتیاز ≥۷. امتیاز قاعده‌محور است و با داده تاریخی بهینه نشده.
- حداکثر ۲۰ هشدار در هر اجرا، مرتب‌شده بر اساس امتیاز و حجم. زمان تکرار AWAKENING/EARLY BUY WATCH سی دقیقه، MOMENTUM پانزده دقیقه. هشدارهای انواع مختلف مستقل‌اند. برای یک نماد در چند صرافی، ادغام فقط در صورت جهت حرکت همسو، اختلاف قیمت حداکثر ۵٪ و عدم تضاد فشار خرید/فروش انجام می‌شود. این تطبیق نماد heuristic است و هویت قطعی دارایی را ثابت نمی‌کند. DEX بر اساس شبکه و آدرس جفت تفکیک می‌شود.
- DEX: کشف محدود به پروفایل‌ها، توکن‌های boost شده، فهرست trending در GeckoTerminal و توکن‌های دیده‌شده در ۲۴ ساعت اخیر. حداکثر ۱۰۰ توکن هر نوبت، نقدینگی حداقل ۵۰ هزار دلار، عمر استخر حداقل یک ساعت، حداقل ۱۰ تراکنش ۵ دقیقه. برای هر توکن پرنقدینگی‌ترین جفت قابل مشاهده انتخاب می‌شود. این اسکن تمام DEXها نیست و boost پولی می‌تواند ترکیب فهرست کشف را تغییر دهد. امتیاز boost ندارد. پوشش شبکه‌های solana, ethereum, bsc, base, arbitrum, polygon, avalanche.
- WHALE عمداً حذف شده؛ سفارش یا معامله ثبت نمی‌شود.

## راهنمای پیام و گزارش

`Move` در CEX تغییر قیمت باز تا بسته‌شدن کندل آخر است؛ در DEX تغییر پنج‌دقیقه‌ای منبع. `Vol 5m` حجم دلاری یا معادل USDT؛ `Extra volume` مقدار اضافی نسبت به مبنا. `High-volume candles` تعداد کندل‌های پرحجم در سه کندل اخیر نسبت به همان مبناست. `BUY/SELL` از فشار معاملات (بالای ۵۵٪ یا زیر ۴۵٪ سهم خرید)؛ در نبود فشار، جهت قیمت با برچسب `(price)` نشان داده می‌شود. فشار Binance Spot از داده کامل کندل است؛ فشار CEXهای فیوچرز فقط اگر نمونه معاملات در بازه دقیق کندل حدود ۹۰ تا ۱۱۰ درصد حجم گزارش‌شده را پوشش دهد محاسبه می‌شود؛ در غیر این صورت N/A. در DEX درصد تعداد تراکنش‌هاست، نه حجم خرید. OI در OKX و KuCoin از نمونه‌های واقعی با زمان ثبت‌شده؛ در Gate از contract_stats اگر دو نمونه پنج‌دقیقه‌ای با زمان دقیق وجود داشته باشد. KuCoin ممکن است داده حجم یا OI لازم را در فهرست عمومی ندهد؛ تنها برخی نامزدها با endpoint جزئیات تکمیل می‌شوند. در اسپات و DEX مقدار OI ندارد. لینک نمودار CEX با قالب نماد TradingView ساخته می‌شود و ممکن است برای نماد خاص نیاز به جست‌وجوی دستی داشته باشد؛ DEX مستقیم به جفت ارزی لینک دارد.

گزارش `Scan and notify`:
```
OKX: listed=... eligible=... attempted=... analyzed=... errors=... unattempted=... candidates=... OI=...
GATE: ...
KUCOIN: ...
BINANCE_SPOT: ...
DEX: tokens=... pools=... batches_ok=... errors=... candidates=...
V5 SUMMARY sources={...} raw=... combined=... sent=...
```
`eligible`: بازارهای عبور کرده از فیلتر اولیه (در KuCoin شامل گردش ناشناخته نیز هست). `analyzed`: داده کافی و تازه برای تحلیل. `errors`: داده ناقص یا درخواست ناموفق. `unattempted`: بازارهایی که سقف زمان یا تعداد مانع بررسی شده. `candidates`: تعداد هشدار قبل از محدودیت تکرار/ادغام. `sent`: تعداد پیام واقعی. اگر یک منبع 403/451 بدهد، مسیر آن متوقف می‌شود و سایر منابع ادامه می‌دهند. اگر هیچ منبعی داده قابل تحلیل ندهد کل اجرا خطا می‌شود. پاسخ منبع موفق در یک اجرای GitHub پایداری دسترسی آینده را تضمین نمی‌کند.

تنظیمات فقط در `config.json` هستند. برای غیر فعال کردن منبع، مقدار آن در `sources` را `false` کنید. افزایش تعداد دفعات اجرای سقف زمان را تضمین نمی‌کند. در مخزن عمومی GitHub Actions استاندارد عموماً بدون هزینه اشتراک است، اما قواعد GitHub و محدودیت APIها همچنان اعمال می‌شوند. فایل وضعیت عمومی است و تاریخچه OI، توکن‌ها و شناسه هشدار را در Git نگه می‌دارد؛ توکن بات و Chat ID در آن ذخیره نمی‌شوند. چنانچه مخزن خصوصی باشد سهمیه رایگان متفاوت است. اجرای دوره‌ای رصد لحظه‌ای WebSocket نیست؛ سیگنال‌های کوتاه‌مدت ممکن است از دست بروند.
